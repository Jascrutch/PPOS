    Sensitivity Analysis
    Shifts each criterion's weight by ±15% (proportionally redistributed across the other three) and reports whether the rank-1 candidate holds. Use this to decide how much to trust the top recommendation.
    Monte Carlo Simulation
    Propagates uncertainty in the AI's V/P/S/Cost/risk estimates through to a distribution of plausible rankings. Each input is sampled from a triangular distribution whose width is set by its Confidence rating — low confidence widens the bounds. "P(rank 1)" is the percentage of simulated scenarios where a candidate is the top choice, i.e. how robust the recommendation is to uncertainty in the underlying scores.

    Decision Subject
    In one short phrase (under 60 characters), what is this decision about?
    Examples
    • "COO hire timing and scope"
    • "Refinance senior debt — current vs. new bank"
    • "Exit timeline — sell to PE vs. continue operating"
    • "Open second location — Dallas market"
    2
    Decision Question
    The actual question. Frame as a question with concrete options, magnitudes, and timing.
    A strong question has three properties
    • Binary or small option set ("A vs. B vs. defer"), not open-ended
    • Includes key terms or magnitudes — prices, timelines, structures
    • Surfaces the real tension you're wrestling with
    3
    Decision Authority
    Who has authority to make this decision? Roles, not just names.
    Include formal and informal authority — spouse, family, board, bank with veto. Recommendations will be calibrated to address actual decision-makers.
    4
    Success Criteria
    How will you know — 6 or 24 months later — whether it worked?
    Quantitative target + timeframe + constraint not to violate.
    5
    Constraints
    What can you NOT do, even if it would be optimal?
    Hard limits, not preferences. Bank covenants. Regulatory. Personal guarantees. Communicated commitments. Family commitments. Contractual obligations. Preferences and reputational concerns go in Section 8 instead.
    6
    Available Evidence
    What do you actually know — concrete evidence, numbers, sources?
    This is the field most clients fill weakly. Push for specifics. Numbers over adjectives. Sources where possible. Direct quotes where relevant.
    7
    Decision Deadline
    When does this need to be made? A real date, not "soon."
    If there is no real deadline, say so explicitly.
    8
    Anything Else Relevant
    The most important field. Context that doesn't fit cleanly elsewhere.
    If you only fill one field thoroughly, fill this one. Your personal financial situation. Your age and post-decision life plan. Family dynamics. Banking relationship history. Prior similar attempts. Industry politics. Your gut instinct and what's driving it. What you're most worried about. Who might object and what they'd say.

    Microsoft 365 — Auto-Save Reports
    Connect PPOS to your company Microsoft 365 to auto-save reports. Shared reports upload to the company SharePoint site (visible to all founders within ~1 minute). Private reports upload to your personal OneDrive (visible only to you; you can share later from OneDrive if you want). Requires a one-time Azure AD app registration — see the runbook below.
    📖 Runbook: One-time Azure AD app registration (15 min)
    Step 1: Register the app in Azure AD.
    Go to entra.microsoft.com → Sign in as the Profit Pulse Inc. global admin → Applications → App registrations → New registration.
    • Name: Profit Pulse Operating System
    • Supported account types: Accounts in this organizational directory only
    • Redirect URI: leave blank (Device Code Flow doesn't need one)
    Click Register. On the next page, copy the Application (client) ID and Directory (tenant) ID into the fields above.

    Step 2: Enable public client / Device Code Flow.
    In the app's left menu → Authentication → Advanced settings → "Allow public client flows" → set to Yes → Save.

    Step 3: Add API permissions.
    Left menu → API permissions → Add a permission → Microsoft Graph → Delegated permissions. Add:
    • Files.ReadWrite (own OneDrive)
    • Files.ReadWrite.All (all files user can access)
    • Sites.ReadWrite.All (SharePoint sites)
    • User.Read (basic profile, usually pre-added)
    • offline_access (refresh tokens)
    Click "Add permissions," then click "Grant admin consent for Profit Pulse Inc." at the top.

    Step 4: Fill in SharePoint paths.
    SharePoint Site URL is the full URL to your company SharePoint site (e.g., https://profitpulseinc.sharepoint.com/sites/PPOS). The folders will be created automatically if they don't exist.

    Step 5: Save and connect.
    Click Save Configuration above, then Connect Microsoft 365. A code will appear — open the link, paste the code, sign in with your work account. Done. Each founder repeats this last step on their own machine; they all share the same Client ID and Tenant ID.
